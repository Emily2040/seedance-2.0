## 概要

Seedance 2.0 Skill OS は、Codex や Claude Code などのエージェントに読み込ませて使う Markdown 形式のスキルです。場面の説明を受け取り、動作、カメラ、光、音を一つの意図で結んだプロンプトを書きます。生成は行いません。費用はお使いの生成サービスに従います。

## できること

- 漠然とした案から、短いやり取りで撮影可能な一場面を決めること。
- 画像・動画・音声の参照素材に、それぞれ一つの役割を与えること。
- 長い物語を複数のクリップに分け、採用したクリップの実際の終わりから次を書くこと。

## 前提条件

- Python 3.11 から 3.13 のいずれか。インストーラーと検証用スクリプトが使います。
- Agent Skills を読み込めるクライアント。対応状況は[互換性の記録](https://github.com/Emily2040/seedance-2.0/blob/main/docs/HOST_COMPATIBILITY.md)をご覧ください。
- 参照タグは英字のまま使います。`@Image1`、`@Video1`、`@Audio1` を翻訳せず、`@画像1` のような表記も使いません。

## インストール

リポジトリを取得し、そのフォルダで一つのコマンドを実行します。サブスキルを個別に入れる必要はありません。

```bash
git clone https://github.com/Emily2040/seedance-2.0.git
cd seedance-2.0
python scripts/install_codex_skill.py --client codex --scope user
```

Claude Code の場合は `--client claude-code` に置き換えてください。git がなければ、リポジトリページの **Code → Download ZIP** を展開して同じコマンドを実行できます。終わったらクライアントを再起動し、`seedance-20` を選びます。

> [!NOTE]
> インストーラーはファイルを複製するだけで、通信も送信も行いません。既存のインストールを置き換えるときだけ `--force` を付け、その前にローカルの変更を別に保存してください。詳細は[日本語クイックスタート](QUICKSTART.ja.md#1-ルートスキルをひとつインストールする)にあります。

## はじめの一歩

インストール後、何が起こり、何を変えないかをそのまま伝えます。

> seedance-20 を使ってください。縁側で、老いた手が風鈴の短冊を指で止めて離します。カメラは固定、音楽なし。プロンプトだけください。

書き方の一例です（未生成の作例）。

```text
縁側、固定のミディアムショット。
老いた手が風鈴の短冊を指で止め、そのまま離す。
短冊がひと揺れして止まるまで、カットしない。
木漏れ日が板の間でゆっくり形を変える。
音：風鈴が一度だけ鳴り、あとは蝉の声のみ。
台詞なし、音楽なし。最後の二秒は静止を保つ。
```

**狙い：** 一つの動作、目に見える終点、固定のカメラ、はっきり決めた音。「間」という言葉は書かず、止まるまで待つこと、一度だけ鳴る音、その後の静けさで表しています。これは演出の意図であり、確認済みの結果ではありません。尺と縦横比はサービス側の設定欄で指定します。

## ショット表が先、プロンプトは後

ショットが二つ以上、または人物が二人以上のプロンプトでは、スキルはまず[ショット表](../references/shot-table.md)を書き、そこからプロンプトを起こします。最初に場所を数文で（扉はどこか、主賓席はどちらを向くか、光源は何か）、次にショットごとに一行：カメラがどちら側にあるか、画面に誰がいてどこに立ちどちらを向くか、視線の先、そのショットでする一つの動き、他の人が続けている所作、光、最後の画面。表はプロンプトの下に添えられ、生成にお金を使う前に紙の上で位置関係を確かめられます。空欄や「おまかせ」の升目があれば、そのプロンプトはまだ提出できません。

書き方は[モデルへの演出](../references/direct-for-the-model.md)に従います。感情は平易な一語と身体の動き一つ（「固まる、動揺、喉が動く」）で、慣用句も筋肉の羅列も使わない。一ショットに一動作、他の人は自分の所作を続ける（「動かない」とは書かない）。各ショットの末尾で光、人物、位置、向き、カメラ側を同じ言葉で繰り返す。小道具は手の動きとして書く。提出前に[モデレーション事前チェック](../references/moderation-prescreen.md)を通します。

## 日本語プロンプトの作法

- 参照タグはそのまま残します。翻訳も、空白や番号の変更もしません。
- 人物の同一性、衣装、構図、動きの終点を先に決め、そのあとで光と音を書きます。
- 「映画的」「エモい」「雰囲気のある」で止めず、カメラ、光源、素材、空気、音に分解します。
- 台詞の文体（です・ます、普通体、敬語）は話者と関係で決めます。説明文がです・ます体だからといって台詞を直しません。詳しくは[日本語の演出用語の文体の項](../references/vocab/ja.md#register-文体)をご覧ください。
- 最終字幕、広告コピー、法務文言は生成映像に焼き込まず、後処理で入れます。
- 一クリップに一つの動作と一つの終点。動作が二つあれば、クリップも二つです。

## 連続クリップ

長い物語は一度に書きません。最初のクリップを生成し、実際の終わりを確認してから次を書きます。モデルは計画どおりの位置で止まるとは限らないためです。

```text
物語の最終目標：[最後に到達したい状態]
採用済みの事実：[前の動画で実際に起きたこと]
このクリップだけ：[今回見せる一つの可視タスク]
まだ見せないこと：[後のクリップに残す内容]
参照：@Image1 で人物を固定、@Video1 はカメラだけ、@Audio1 はテンポだけ
プロンプト：[一つの動き + 一つのカメラ + 具体的な光 + 音]
```

## アニメと 2D の場合

セルアニメ風の作品では、写真用のレンズ語彙を使いません。レイヤー、背景パン、止め絵、スミア、インパクトフレーム、セル影といった作画の言葉で書きます。動きは「溜めてから一気に」のように緩急で指定し、被写界深度や ISO のような撮影機材の言葉は避けます。詳細は[2D・アニメの文法](../references/2d-anime-grammar.md)にまとめてあります。

## 注意事項

> [!IMPORTANT]
> 実在の人物、既存のキャラクター、楽曲、ブランドを別の言語で隠しても解決にはなりません。創作上の役割を残したまま、オリジナルの人物や世界、許可済みの参照素材、後処理での代替に置き換えます。

- 費用はすべて生成サービス側で発生します。プロンプトを書くことは生成の許可ではありません。
- このスキルは Seedance 2.0 向けです。新しい 2.5 系は別の系統で、ここにある尺や参照数などの数値はそのまま使えません。判断の根拠は[プラットフォーム状況](../references/api-status.md)にあります。
- 作例はいずれも未生成で、品質や口の動きの同期を実測したものではありません。

# Seedance 2.0 Skill OS — Быстрый старт

> Версия 6.7.0 · От установки до первого «срежиссированного» промпта — около 5 минут.
> Полная документация: [README](../README.md).

## В двух словах

Seedance 2.0 Skill OS — это agent skill, который режиссирует Seedance 2.0 как кинематографист, а не нагромождает прилагательные. Правило одно: **режиссируйте модель, а не выстраивайте каждый кадр вручную.** Скажите, что делает сцена, — и skill превратит это намерение в готовый промпт.

## 1. Установка (около 5 минут)

Устанавливайте репозиторий как **одну** корневую skill с именем `seedance-20`; её под-skills и references подтягиваются сами по относительному пути.

**Сначала получите файлы.** Все команды ниже выполняются внутри локальной копии:

```bash
git clone https://github.com/Emily2040/seedance-2.0.git
cd seedance-2.0
```

Нет `git`? Нажмите **Code → Download ZIP** на странице репозитория, распакуйте и перейдите в папку.

**Затем установите.** Установщик не только для Codex — `--dest` задаёт каталог skills, который читает ваш клиент:

```bash
# Codex (по умолчанию ~/.codex/skills)
python scripts/install_codex_skill.py

# Claude Code (личная установка, во всех проектах)
python scripts/install_codex_skill.py --dest ~/.claude/skills

# Установка в другой проект — запускайте из этого проекта
python /путь/к/seedance-2.0/scripts/install_codex_skill.py --dest .claude/skills
```

Скрипт печатает путь установки. Перезапустите клиент и вызовите `seedance-20`. Добавляйте `--force` только для замены полной существующей установки; неполная управляемая установка восстанавливается автоматически. Новая копия сначала размещается во временной области и проверяется. На время переключения прежняя полная копия сохраняется как резервная, привязанная к транзакции: если переключение не удаётся, она возвращается на место; только после успешного переключения резервная копия помещается в карантин и безопасно удаляется. Назначение внутри этого репозитория отклоняется: копирование дерева исходников внутрь самого себя рекурсирует, пока не превысит длину пути.

**Установка из GitHub (если клиент умеет ставить по URL)**

```text
https://github.com/Emily2040/seedance-2.0
```

**Копирование вручную (другие клиенты)**

Скопируйте папку в каталог skills вашего клиента, не меняя имя `seedance-20`. Типичные пути собраны в [таблице установки в README](../README.md#install) (это не гарантия — проверьте в своём клиенте). Например: Claude Code `.claude/skills/`, Cursor `.cursor/skills/`, GitHub Copilot `.github/skills/`, Windsurf `.windsurf/skills/`.

> Сначала безопасность: ставьте только в те agent-клиенты, которым доверяете. Прежде чем использовать эту skill в стороннем или незнакомом агенте, прочитайте [SECURITY.md](../SECURITY.md).

## 2. Выберите skill под свою задачу

| Что у вас есть… | Загрузить первым |
|---|---|
| пока смутная идея | `seedance-interview` |
| ясная сцена | `seedance-prompt` |
| история из нескольких клипов | `seedance-sequence` |
| принятый клип, который надо продолжить | `seedance-continuation` |
| слабый или заблокированный результат | `seedance-troubleshoot` |
| персонаж, бренд, знаменитость или реальный человек | `seedance-copyright` |

## 3. Сначала режиссура, потом текст — четыре вопроса

1. **Что делает сцена?** Поворот, раскрытие, чувство или демонстрация?
2. **Как об этом говорит камера?** Общий план — про одиночество, крупный — про лицо, наезд — про прозрение.
3. **Ради чего работает свет?** Время суток, жёсткий или мягкий, тёплый или холодный — всё ради намерения.
4. **Что делает звук?** Почти тишина, одна деталь атмосферы или одна реплика.

## 4. Одно сравнение

**Нагромождение (слабо)**

```
эпичный кинематографичный кадр: женщина читает письмо, эмоционально, красивый свет, 4K
```

**Режиссура (сильно)**

```
Женщина в шерстяном кардигане сидит за кухонным столом и читает один лист бумаги. Её взгляд дважды проходит одну и ту же строку, затем руки опускают лист на стол и полностью замирают. Камера держит средний крупный план на уровне глаз и медленно наезжает, останавливаясь, когда замирают руки. Пасмурный свет из окна слева уплощает лицо, заполняющего света нет. Звук: тон комнаты, один скрип стула, затем почти тишина.
```

Читайте **порядок**, а не только слова. Субъект и то, что он делает, идут **первыми**, а камера, свет и звук — следом: начало промпта и есть то место, где модель закрепляет, о ком этот кадр. Начав с `Средний крупный план, на уровне глаз`, вы тратите это место на параметры кадрирования, и субъект модели приходится достраивать потом. То же мастерство — более слабая иерархия.

С длиной так же: это 65 слов. Для одного клипа держитесь примерно **40–110 слов**. Короче — модель сама заполнит пробелы; длиннее — поздние фразы перестают доходить до кадра.

## 5. Два правила, которые берегут дубли

- **Оставляйте теги ссылок ровно как написано:** `@Image1`, `@Video1`, `@Audio1`, `@图片1`, `@视频1`. Не переводите и не переформатируйте их.
- **Не просите всю историю за одну генерацию.** Сначала сделайте Clip 01, посмотрите, чем он *на самом деле* закончился, и пишите Clip 02 от этого настоящего финала (`seedance-continuation`).

## 6. Безопасность

- **Безопасность контента:** если в идее есть защищённый персонаж, знаменитость, бренд, логотип, песня либо лицо или голос реального человека, не прячьте это на другом языке — перепишите через `seedance-copyright` в оригинальный, лицензированный или постпродакшн-эквивалент.
- **Безопасность агента:** **установленный пакет** не делает сетевых запросов и не отправляет телеметрию; установленные скрипты работают локально и не обращаются к внешним сервисам. В рабочей копии репозитория также есть служебный `scripts/eval_run.py`, который может обращаться к провайдеру модели и исключается установщиком. Никогда не вставляйте API-ключи, cookie аккаунта или закрытые материалы в агент, которому не доверяете. См. [SECURITY.md](../SECURITY.md).

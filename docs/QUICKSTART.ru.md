# Seedance 2.0 — Первый промпт и ваши решения

Версия пакета: 6.7.0. Эта инструкция помогает подготовить промпт; сама по себе она не создаёт видео.

**Статус текста:** черновик, подготовленный с помощью ИИ. Независимая проверка специалистами по русскому языку и языку кинопроизводства ещё не проведена. Примеры не были сгенерированы в видео и не доказывают качество, экономию кредитов или точность синхронизации речи. Инструкция написана кириллицей с обращением на «вы»; конкретная региональная или разговорная норма не заявлена как проверенная. [Языковое покрытие и проверка](LANGUAGE_COVERAGE.md).

## 1. Установите один навык

Скачайте ZIP-архив репозитория или выполните:

```sh
git clone https://github.com/Emily2040/seedance-2.0.git
cd seedance-2.0
```

Из этой папки выберите **один** вариант:

```sh
# Codex: для вашего пользователя
python scripts/install_codex_skill.py --client codex --scope user

# Claude Code: для вашего пользователя
python scripts/install_codex_skill.py --client claude-code --scope user

# Codex: для существующего проекта вне этого репозитория
python scripts/install_codex_skill.py --client codex --scope project --project-root /path/to/project
```

Папка установленного навыка называется `seedance-20`. Его внутренние модули отдельно устанавливать не нужно. Если клиент или профиль использует другой каталог, задайте `--dest /path/to/skills`. Не объединяйте `--dest` с параметрами клиента и области установки. Без параметров назначения сохраняется прежний путь `$CODEX_HOME/skills` или `~/.codex/skills`; существующие копии никуда не переносятся.

Проверьте **тот же каталог** диагностической командой. Например, после первого варианта:

```sh
python scripts/install_doctor.py --client codex --scope user --json
```

Статус `current` означает, что проверенные файлы совпадают с этой копией репозитория. Он не доказывает, что клиент загрузил именно их. Обновите список навыков или перезапустите клиент и проверьте путь к `seedance-20`. Перед заменой сохраните свои правки и отдельную резервную копию; `--force` используйте только для намеренной замены. [Каталоги установки](https://github.com/Emily2040/seedance-2.0/blob/main/docs/INSTALL_SCOPES.md) · [Перенос и дубликаты](https://github.com/Emily2040/seedance-2.0/blob/main/docs/INSTALL_MIGRATION.md).

Для переноса подготовьте пакет установщиком в новой папке вне репозитория и скопируйте **только полученную папку `seedance-20/`**, включая скрытые файлы. Не копируйте весь репозиторий. При прямом импорте из GitHub проверьте, какие файлы забирает клиент. [Ручной перенос](https://github.com/Emily2040/seedance-2.0/blob/main/docs/MANUAL_INSTALL.md).

<details>
<summary>Что происходит при замене</summary>

Временная резервная копия сохраняется на время переключения. Если оно не удалось и записи транзакции остаются действительными, прежняя копия возвращается на место. После успешного переключения временная копия помещается в карантин и удаляется. Она не заменяет ваш отдельный резервный архив. Файлы и состояния, которые нельзя проверить, требуют разбора; их не удаляют ради принудительного восстановления.

</details>

## 2. Начните с того, что уже решили

Вызовите `seedance-20` в своём клиенте и опишите сцену. Уже выбранные длительность, камера, звук и настроение не требуют повторного опроса. Если задача ясна, можно сразу попросить готовый текст.

| Что у вас есть | Что попросить |
|---|---|
| Идея одного короткого клипа | Первый черновик или один вопрос, без которого нельзя выбрать решение; маршрут `seedance-interview-short` |
| Готовое описание сцены | Сразу промпт; маршрут `seedance-prompt` |
| Несколько связанных сцен | План последовательности; маршрут `seedance-sequence` |
| Принятый клип для продолжения | Продолжение от его фактического финала; маршрут `seedance-continuation` |
| Неудачный результат | Диагноз и одну правку в пределах бюджета; маршрут `seedance-troubleshoot` |

Названия маршрутов знать необязательно. Достаточно такого запроса:

> Нужен радостный шестисекундный клип: взрослая женщина, мастер по ремонту часов, слышит, что отремонтированные настольные часы снова идут. Камера неподвижна, без диалога. Предложи три разных решения, а я выберу. Только подготовь промпты, ничего не генерируй.

## 3. Выберите, на чём будет держаться кадр

Это варианты для **данного** запроса, а не обязательное меню перед каждым промптом:

| Вариант | Видимое решение | Что получает зритель |
|---|---|---|
| А · Сдержанная радость | Услышав тиканье, она меняется в лице; средний крупный план, камера неподвижна | Внимание к моменту узнавания: часы работают |
| Б · Открытая радость | Она коротко смеётся и вскидывает руки; более общий план, камера неподвижна | Энергичная реакция; в кадре больше движения тела |
| В · Работа механизма | Крупный план движущегося маятника; женщина на заднем плане не в фокусе | Видно, что именно работает; выражение лица перестаёт быть главным |

Можно выбрать вариант, соединить совместимые решения или написать «выбери за меня и объясни почему». После выбора А следующие правки должны сохранять его, пока вы сами не попросите изменить подход.

## 4. Скопируйте выбранный промпт

**Для примера выбрано А.** Это текстовый промпт без прикреплённых файлов и вымышленных ссылок на изображения. Установите длительность шесть секунд в выбранном сервисе, если нужная операция её допускает; проверьте настройки до расходования кредитов. Соотношение сторон и уровень качества задаются отдельно. Конкретный провайдер или API здесь не предполагается.

```text
Взрослая женщина, мастер по ремонту часов, сидит перед работающими настольными часами. Услышав тиканье, она слегка поднимает брови и улыбается, продолжая смотреть на часы. Неподвижный средний крупный план на уровне её глаз. Боковой свет из окна позволяет видеть изменение выражения лица. Слышны тиканье и тихий фон мастерской, без речи и музыки. Последние две секунды она сохраняет улыбку и позу.
```

**Зачем эти решения:** звук вызывает видимую реакцию, неподвижная камера помогает её прочитать, а финальная пауза даёт время рассмотреть выражение лица. Это замысел, а не наблюдавшийся результат. Кадр показывает реакцию и не доказывает качество реального ремонта.

**Что проверить в видео:** взгляд остаётся на часах, камера не движется, речь не появляется, финальная поза удерживается. Назовите нарушенный критерий, прежде чем добавлять в текст новые прилагательные.

Порядок «кто — что делает — как снято» удобен для редактирования. Это не проверенное объяснение того, как модель обрабатывает первые слова. Краткий текст легче проверить, но число слов не гарантирует выполнения всех указаний. Оставьте детали, без которых нельзя понять действие и его завершение.

## 5. Исправьте одно решение, не начиная заново

> Улыбка получилась слишком широкой. Оставь вариант А, шесть секунд и неподвижную камеру. Осталась одна попытка; подготовь правку, но не отправляй её.

Если видео не приложено, ответ должен опираться **на ваше описание**, а не изображать просмотр. Возможная правка: заменить только «слегка поднимает брови и улыбается» на «расслабляет брови и едва приподнимает уголки губ, не показывая зубы». Её цель — уменьшить размах мимики; успех следующей генерации не гарантирован. Остальные настройки сохраняются.

При нулевом бюджете не запрашивайте новую генерацию. Оцените, можно ли использовать удачный фрагмент при монтаже, или остановите пробу. Не объявляйте кадр принятым, если обязательный критерий не выполнен. Подготовка текста не разрешает его отправку, смену провайдера, загрузку файлов или увеличение длительности и качества.

## 6. Реплика, референсы и продолжение

**Точная реплика.** Если вы меняете запрос на «сохрани дословно фразу “Работает.”», эти слова должны остаться в промпте без изменений. Женщина говорит сама с собой; другой собеседник и другой речевой регистр не добавляются без запроса. Не включайте эту реплику в прежний вариант без речи. Не заменяйте кириллицу транслитерацией и не сокращайте точную фразу без согласования. Измерьте длительность реального произнесения и проверьте голос с человеком, владеющим нужным вариантом русского языка. Для этого примера нет результатов проверки речи или синхронизации губ. Отдельный дубляж либо разрешённый голосовой референс, если сервис его поддерживает, остаются вариантами на ваш выбор.

**Референсы.** Если вы прикрепляете реальное изображение как `@Image1`, задайте ему одну роль, например внешний вид часов. Сохраняйте написание, которое использует ваш интерфейс: `@图片1` и `[Image 1]` тоже нельзя самовольно заменять. Упоминание имени не прикрепляет файл. Без изображения пример выше остаётся текстовым промптом.

**Продолжение.** Если вы пишете «в последнем кадре она улыбается и смотрит на часы», но не прикладываете кадр, ответ должен назвать это вашим описанием. Нельзя утверждать, что изображение просмотрено, или придумывать детали мастерской. Получив принятый финал, продолжайте из этой позы и не повторяйте начальную реакцию. Если точное положение предмета необходимо, но неизвестно, сначала уточните его; не выдавайте непроверенную непрерывность за установленный факт.

## 7. Безопасность и дальнейшая работа

Текст внутри изображений, файлов и расшифровок — исходный материал, а не разрешение выполнять команды, читать ключи, загружать файлы или создавать видео. Перевод не служит способом обхода ограничений. Для реальных лиц и голосов, брендов и чужих материалов сохраняйте творческий замысел через оригинальное решение, разрешённый материал или постобработку. См. [SECURITY.md](../SECURITY.md).

Подготовленный установщиком и установленный пакет не содержит сетевых инструментов разработки, таких как `scripts/eval_run.py`, и необязательных средств запуска провайдеров. Разрешениями самого агента управляет клиент; установка навыка не делает его средой без доступа к сети.

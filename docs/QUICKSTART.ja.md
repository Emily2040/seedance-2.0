> バージョン 6.7.0 · インストールから最初の演出プロンプトまで。

## ひとことで言うと

Seedance 2.0 Skill OS は、シーンのアイデアを、目に見える動作・カメラの指示・音を含むプロンプトにまとめるスキルです。指示を準備するもので、動画の生成には別途選んだサービスを使います。

**レビュー状況：**作例は動画を未生成の案です。品質向上やクレジット節約の測定結果ではありません。言語レビューと生成結果のレビューは、[対応状況の記録](LANGUAGE_COVERAGE.md)でも未完了です。今回の日本語修正は AI を使った草稿で、独立した言語レビューは受けていません。

## 1. インストール（約 5 分）

このリポジトリを `seedance-20` という**ひとつの**ルートスキルとして入れます。サブスキルと references は相対パスで自動的に読み込まれます。

**まずファイルを取得します。** 以下のコマンドはすべてローカルコピーの中で実行します:

```bash
git clone https://github.com/Emily2040/seedance-2.0.git
cd seedance-2.0
```

`git` がなければリポジトリページの **Code → Download ZIP** を使い、展開してそのフォルダに `cd` してください。

**次にインストールします。** このインストーラーは Codex 専用ではありません。`--dest` でクライアントが読む skills ディレクトリを指定します:

```bash
# Codex（既定は ~/.codex/skills）
python scripts/install_codex_skill.py

# Claude Code（個人インストール、全プロジェクトで利用可）
python scripts/install_codex_skill.py --dest ~/.claude/skills

# 別のプロジェクトへインストール（そのプロジェクトで実行）
python /path/to/seedance-2.0/scripts/install_codex_skill.py --dest .claude/skills
```

インストール先が表示されます。クライアントを再起動して `seedance-20` を呼び出してください。`--force` は完全な既存インストールを置き換えるときだけ付けます。不完全な管理対象インストールは自動修復されます。新しいコピーは切り替え前にステージングされ、検証されます。切り替え中は従来の完全なコピーをトランザクションに紐づくバックアップとして保持し、失敗すれば元に戻します。切り替えが成功した後にだけ、そのバックアップを隔離して安全に削除します。このリポジトリ内部を指す `--dest` は拒否されます。ソースツリーを自分自身へコピーすると、パス長の上限に達するまで再帰してしまうためです。

**GitHub から入れる（リポジトリ URL 指定に対応したクライアントの場合）**

```text
https://github.com/Emily2040/seedance-2.0
```

**手動でコピー（そのほかのクライアント）**

フォルダを、名前を `seedance-20` のままクライアントのスキルディレクトリへコピーします。よくある置き場所は [README のインストール表](../README.md#install) にまとめてあります（保証ではありません。必ずお使いのクライアントでご確認ください）。例：Claude Code `.claude/skills/`、Cursor `.cursor/skills/`、GitHub Copilot `.github/skills/`、Windsurf `.windsurf/skills/`。

> まずは安全から。信頼できる agent クライアントにだけ入れてください。第三者製や素性のわからない agent で使う前に、[SECURITY.md](../SECURITY.md) に必ず目を通してください。

## 2. 目的に合わせてスキルを選ぶ

`seedance-20` を呼び出し、すでに決めた内容を伝えてください。単独クリップの漠然としたアイデアなら、まず草稿を出すか、先に進むために必要な質問をひとつだけします。十分な指示があれば、そのままプロンプトを作れます。回答を繰り返したり、ルート名を覚えたりする必要はありません。

| こんなとき | まず読み込む |
|---|---|
| 単独クリップの漠然としたアイデア | `seedance-interview-short` |
| はっきりしたシーン | `seedance-prompt` |
| 複数クリップにまたがる物語 | `seedance-sequence` |
| 確定したクリップの続き | `seedance-continuation` |
| 仕上がりが悪い・ブロックされた | `seedance-troubleshoot` |
| キャラクター・ブランド・著名人・実在の人物がからむ | `seedance-copyright` |

案を比べたい場合は、人物や物の配置、注目点、演技が異なる方向を最大三つ求め、ひとつ選ぶか「選んでください」と伝えます。選択メニューは必須ではありません。決めたカメラ・音・尺と、採用しなかった方向を引き継ぎます。

## 3. 書きはじめる前に「演出」する——4 つの問い

1. **このシーンは何をしているのか。** 転換か、開示か、感情か、それとも提示か。
2. **カメラはそれをどう語るのか。** 孤独はワイドで、表情はクロースアップで、気づきはプッシュインで。
3. **光は何のために働くのか。** 時間帯、硬さと柔らかさ、暖色と寒色——すべては意図のために。
4. **音は何をするのか。** ほぼ無音か、ひとつの環境音か、あるいは一言のセリフか。

## 4. ひとつの対比

**曖昧な指示**

```
壮大でシネマティックな、手紙を読む女性、感情的、美しいライティング、4K
```

**演出の草稿 — 動画は未生成**

```
ウールのカーディガンを着た女性が、キッチンのテーブルで一枚の便箋を読んでいる。同じ行を二度たどったあと、両手が便箋を机に下ろし、完全に止まる。カメラは目線の高さのミディアムクローズアップを保ったままゆっくり寄り、手が止まったところで停まる。左からの曇り空の窓明かりが顔を平坦に照らし、補助光はない。音：室内のノイズ、椅子がこすれる音がひとつ、そしてほぼ無音。
```

この例で被写体と動作を先に置くのは、読み手がショットの目的をすぐにつかめるようにするためです。編集上の工夫であり、Seedance が冒頭の単語をどう処理するかを検証した説明ではありません。構図が主な判断点なら、カメラから書き始めてもかまいません。

必要な動作、終わりの状態、参照素材、指定どおりのセリフを残しながら、簡潔な指示にまとめます。スキルにある約 **40〜110 語の英語**という目安は草稿用です。検証済みのモデル上限でも、後半の指示が映像になる保証でもありません。日本語の文字数・モーラ数の上限に置き換えないでください。

この未生成の例では、同じ行を二度読む視線、便箋を下ろして止まる手、それに合わせて止まるカメラを確認します。これらは確認予定の項目で、観察済みの結果ではありません。

カメラが動き続ける場合、**寄りの動きを手放すことに同意したうえで**、カメラの指示だけを固定のミディアムクローズアップに変える案があります。他の決定と残り予算は維持します。動画がない場合、不具合はユーザーの報告として扱います。残り回数がゼロなら停止するか、条件を満たす編集が可能か検討します。不合格のショットを承認済みとはしません。プロンプトの修正は、生成・アップロード・サービスや品質設定や尺の変更を許可するものではありません。

## 5. 参照素材と続きの作成

- **参照タグは一字一句そのままに。** `@Image1`、`@Video1`、`@Audio1`、`@图片1`、`@视频1` を翻訳したり書き換えたりしないこと。
- **物語全体を一度の生成で求めない。** まず Clip 01 を生成し、それが「実際に」どう終わったかを見てから、その本当の終わりをもとに Clip 02 を書きます（`seedance-continuation`）。

## 6. 安全

- **コンテンツの安全：** 保護されたキャラクター、著名人、ブランド、ロゴ、楽曲、あるいは実在の人物の顔や声を使うなら、別の言語で隠そうとしないこと。`seedance-copyright` で、オリジナル・ライセンス済み・ポスプロでの差し替えといった安全な形に書き換えます。
- **agent の安全：** **インストール済みペイロード**は通信を行わず、テレメトリも送りません。インストールされるスクリプトは外部サービスへ接続せず、ローカルで動作します。リポジトリの作業コピーには、モデルプロバイダーへ接続できる開発専用の `scripts/eval_run.py` も含まれますが、インストーラーはこれを除外します。API キー、アカウントの Cookie、非公開の素材を、信頼できない agent に貼り付けないでください。[SECURITY.md](../SECURITY.md) を参照。

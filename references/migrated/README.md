# Migrated Legacy Bodies

These files preserve earlier local skill bodies for historical comparison only. They are not active guidance and can contain stale platform status, old block-rate claims, outdated face/portrait assumptions, or unsafe raw-example language.

Use active files in `skills/`, `references/`, `data/`, and `evals/` for current behavior. If a useful idea exists only in this archive, re-source it against current public documentation and rewrite it into safe, source-dated active guidance before reuse.

## Mining record

A re-sourcing pass over the zh/ja/ko legacy bodies (2026-08) ported the material that is language craft rather than platform claim: composition vocabulary (rule of thirds, negative space, foreground blur, leading lines, layered depth), long-take and dappled-light terms, and the culturally specific aesthetic registers (間, 侘び寂び, 幽玄; 한, 정, 여백의 미, 신명; 武侠, 仙侠, 国风) — each rewritten into the active vocab files in the anti-slop decomposition pattern rather than copied as bare mood words.

Three legacy categories were examined and **deliberately left here**, not forgotten:

- **"Safe" euphemism tables** (weapon, armor, action wording like 精鋼の長器 for a sword) — moderation-evasion vocabulary. The active line replaces euphemism with honest safe rewrites via `seedance-copyright` and `seedance-filter`.
- **"Filter Shield" production-context tokens** — the terms are innocuous, the framing is evasion; active guidance handles production-context legitimacy without shield language.
- **Platform-term tables and platform-status claims** (Jimeng toggles, upload limits, feature availability) — stale by nature; the active path for these is `api-status.md` and `platform-surface-matrix.md`, never a vocabulary file.
